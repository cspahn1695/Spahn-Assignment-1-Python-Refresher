This image shows how fib(n) and the time to compute it increase somewhat (but not perfectly) linearly as n increases. The times are total computation times as n grows. The overall trend is that fib(n) increases somewhat linearly for n from 0-70. The code starts a timer before computing fib(1), and after each fib(n) value is computed, the value of the timer at that time is added to the 'times' array. Finally, the computation times are plotted against n values to create the plot. Additionally, the cache is cleared once before any fib(n) values are computed.
